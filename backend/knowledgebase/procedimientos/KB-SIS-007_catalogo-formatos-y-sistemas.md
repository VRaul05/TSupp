# Catálogo de formatos y sistemas

## Formatos

| Clave | Nombre | Quién lo elabora / usa | Para qué sirve |
| --- | --- | --- | --- |
| FOR SIS 01 | Programa de Mantenimiento Preventivo | Informática y Sistemas | Planear las fechas de mantenimiento preventivo. Se archiva como evidencia. |
| FOR SIS 02 | Rutina de Mantenimiento Preventivo | Informática y Sistemas; la firma el usuario | Registrar el preventivo realizado. El usuario la firma de conformidad y se archiva. |
| FOR SIS 03 | Orden de Trabajo | Se genera en SIMACO; la firma el usuario | Registrar un mantenimiento correctivo. El usuario la firma como solicitante y de conformidad al terminar. Se archiva como evidencia. |
| FOR SIS 04 | Registro de Órdenes de Trabajo | SIMACO (automático) | Concentrar todas las FOR SIS 03 e indicar si están abiertas o cerradas. |
| FOR ADQ 01 | Requisición | Informática y Sistemas | Solicitar un mantenimiento o refacción con proveedor externo. Se archiva copia. |
| FOR ADQ 02 | Orden de Compra | Adquisiciones | Contratar el servicio o refacción con el proveedor. Sistemas la firma de aceptación al verificar el servicio. |
| FOR COOR 05 | Evaluación del desempeño de procesos contratados externamente | Responsable de Sistemas e Informática | Evaluar a los proveedores externos al menos una vez al año. |

## Sistemas y canales

| Nombre | Descripción |
| --- | --- |
| SIMACO | Sistema donde se capturan los reportes de mantenimiento correctivo, se generan las órdenes de trabajo (FOR SIS 03) y se registra su cierre (FOR SIS 04). |
| K1000 | Aplicación con la que se reportan los servicios que realiza DMAyF. |
| 072 | Número telefónico para levantar y cerrar los reportes con DMAyF. |
