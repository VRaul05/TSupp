# Proceso de mantenimiento preventivo y correctivo de hardware y software (MAP SIS 01)

## Objetivo

Mantener en óptimas condiciones de uso los equipos de cómputo con los que cuenta el Sistema DIF Municipal, realizando los mantenimientos preventivos programados y atendiendo de manera pronta las solicitudes de los usuarios para realizar los mantenimientos correctivos correspondientes.

## Alcance

El proceso cubre dos tipos de mantenimiento, tanto de hardware como de software:

- **Mantenimiento preventivo:** se realiza de acuerdo con un programa elaborado por Informática y Sistemas (ver KB-SIS-006).
- **Mantenimiento correctivo:** se realiza cuando un usuario reporta una falla (ver KB-SIS-002). Según el diagnóstico puede ser **interno** (KB-SIS-003), **externo con proveedor** (KB-SIS-004) o **externo vía DMAyF** (KB-SIS-005).

## Entradas del proceso

- Elaboración de un programa de mantenimiento preventivo (FOR SIS 01).
- Reporte de mantenimiento correctivo recibido de manera personal o por vía telefónica.
- Captura del reporte en el sistema SIMACO.

## Salida del proceso

Equipo de cómputo en condiciones adecuadas.

## Áreas que participan

| Área | Papel en el proceso |
| --- | --- |
| Usuario | Reporta la falla, firma como solicitante y firma de conformidad la Orden de Trabajo (FOR SIS 03) o la Rutina de Mantenimiento Preventivo (FOR SIS 02). |
| Informática y Sistemas | Elabora el programa preventivo, recibe y captura reportes, diagnostica, realiza el mantenimiento interno, verifica servicios externos, cierra y archiva. |
| Adquisiciones | Elabora la Orden de Compra (FOR ADQ 02) cuando el mantenimiento es externo. |
| Proveedor externo | Recibe la Orden de Compra y realiza el mantenimiento o entrega la refacción solicitada. |
| DMAyF (Subdirección de Sistemas de finanzas) | Realiza el servicio cuando se solicita mediante la aplicación K1000 y el número 072. |

## Personal involucrado

Dirección General, subdirectores, jefes de departamento, responsables, secretarias y auxiliares.

## Recursos (equipo e instalaciones)

Equipo de cómputo, telefonía Cisco, vehículo, herramientas mecánicas, herramientas electrónicas, un área adecuada de mantenimiento y software.
